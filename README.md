# Recipe Collection Webpage

A clean, responsive, and semantic HTML-only webpage showcasing a curated collection of delicious, easy-to-cook recipes. This project is built using modern HTML5 structural elements.

## Features
* **Semantic Structure:** Built entirely with HTML5 layout pages.
* **Interactive Navigation:** Smooth, jump-to-selection anchor links for seamless recipe browsing.
* **Rich Component Layout:** Includes structured data with cooking metrics and proper order & unorder list arranging ingredients.
* **Accessibility-First:** Designed with descriptive tags and screen-reader friendly nesting.
